# JUG — PHYSICAL SPEC. **The document the SPICE work starts from.**

Generated by `../sim/jug_physical_spec.py` (the units bridge). 2026-07-14.
Design: `../DESIGN.md`. Evidence: `../sim/RESULTS.md`.

> ## THE HEADLINE FOR AN ANALOG DESIGNER
> **Almost everything here is extraordinarily loose. Exactly two things are tight.**
>
> The comparator is a **coarse, sloppy, 1-bit decision device that is ALLOWED to be wrong one time
> in five.** It may have large offset. Its threshold may vary 2× across the die. The capacitors may
> mismatch 10×. None of it matters.
>
> **The two things that are NOT negotiable:**
> 1. **The fire must SUBTRACT θ from Ce — never discharge it.**
> 2. **kT/C noise on Ce must be ≤ 0.1 × θ.**

---

## 1. The mechanism, in circuit terms

```
   Ce accumulates signed charge injections (δ · x) and IS NEVER DISCHARGED.
   A SHARED comparator, swept across the array by absorb_ctrl, tests each cell once per sweep:

       |V_Ce − V_bias_e| ≥ θ ?
           YES →  charge-pump Cw by ±1 weight LSB      (dQ = 1.405 fC)
                  SUBTRACT θ from Ce                    ← the residue is KEPT
           NO  →  nothing. The charge stays on Ce.
```

**One shared comparator, time-multiplexed — NOT one per cell.** 1024× cheaper, and the sweep
period gives a **free refractory period** (single fire per sweep). A per-cell comparator would fire
repeatedly on a crossing and **run away** (measured: 271%/fold, network collapses to 18%).

---

## 2. THE ±1 LSB CHARGE PUMP — absolute, no free parameter

| | |
|---|---|
| V_w range | 0.500 – 1.350 V over 121 codes |
| **one weight LSB** | **7.02 mV on Cw** |
| Cw | 200 fF |
| **⇒ dQ_pump** | **1.405 fC, bidirectional** |

A fire must move Cw by **exactly one code**. Over-shooting the code is a gain error on the learning
rate (tolerable — see §4); under-shooting to zero is not (the write becomes a no-op, which is the
whole failure the jug exists to fix).

---

## 3. ⚠ Ce SIZING — **THE ONE TIGHT SPEC**

kT/C noise is sampled **every time the inject switch closes**, so across a fold of **N** injections
it accumulates as `√N · √(kT/Ce)`. The tolerance is **measured, not derived**:

| σ / θ (thermal noise on Ce) | accuracy | vs the 81.96% reference |
|---|---|---|
| **0.05** | **81.75%** | **free** |
| **0.10** | **81.36%** | −0.60pp (at the noise floor) |
| 0.25 | 78.55% | −3.41pp |
| 0.50 | 71.39% | −10.57pp |
| 1.00 | 51.81% | **collapse** |

> ### ⇒ **SPEC: σ(kT/C) ≤ 0.1 × θ.** (0.05 for margin.)
>
> ```
>      √N · √(kT/Ce)  ≤  0.1 · θ_volts
>      ⇒   θ_volts  ≥  (√N / 0.1) · √(kT/Ce)
> ```
>
> ⚠ **N — how often the inject switch samples kT/C — is a CIRCUIT-TOPOLOGY question, not a
> modelling one. THE RELATION is the deliverable; N is yours to fill in.** The table below assumes
> N = 128 (one kT/C sample per injection, one injection per training sample).

| Ce | √(kT/C) | ⇒ minimum θ | Ce swing (≈3θ) | |
|---|---|---|---|---|
| 50 fF | 288 µV | 32.6 mV | 98 mV | ✓ |
| **100 fF** | **204 µV** | **23.0 mV** | **69 mV** | **✓ RECOMMENDED** |
| 200 fF | 144 µV | 16.3 mV | 49 mV | ✓ |
| 500 fF | 91 µV | 10.3 mV | 31 mV | ✓ |
| 1 pF | 64 µV | 7.3 mV | 22 mV | ✓ |

**Ce = 100 fF is adequate: θ ≈ 23 mV, swing ≈ ±100 mV.** Comfortable in a 1.8 V supply.

### ★ Why this is the ONE tight spec, when everything else is loose
Every other perturbation we tested corrupts a **decision** — *when* a synapse fires, or occasionally
*which way*. **Thermal noise corrupts the EVIDENCE.** A wrong-signed fire is undone by the next
correct one, because the residue subtraction **conserves charge**. But **charge that was never real
cannot be subtracted back out.**

> **The sigma-delta can forgive a bad DECISION. It cannot forgive a LIE ABOUT HOW MUCH CHARGE IS
> THERE.**

## 4. THE COMPARATOR — and how little it has to be

| parameter | tolerance | evidence |
|---|---|---|
| **offset** | may be a **large fraction of θ** | ×2 threshold mismatch across the die → **−0.76pp** |
| **wrong-signed decisions** | **up to 20%** | 20% wrong fires → **−0.34pp** |
| **Ce leakage** | one-sided bound only (τ ≫ inter-fire) | met by **~10³** in the real device |
| **Ce matching** | **NON-REQUIREMENT** | **10× log-normal spread → −0.58pp** |
| **firing granularity** | single fire per sweep | multi-fire at the design point: **81.60% vs 81.96%** — no difference |

**Why the sign errors are free:** a wrong fire moves W the wrong way **and subtracts θ in the wrong
direction — i.e. it puts the charge back.** The next correct fire undoes both. Charge is conserved,
so the error self-corrects.

⇒ **This is a much easier comparator than an ADC.** Deleting the Ce-readback path (old §6.3 — which
demanded either a SAR conversion per E-cap, or a 12-bit digital accumulator per synapse) was the
whole point.

---

## 5. ⚠ TWO PARAMETERS THAT MN3_e's DELETION FREED — RE-DERIVE, DO NOT INHERIT

**MN3_e (the E-tail) is deleted. Ce is OUT OF THE SIGNAL PATH.** It is now a storage-and-compare
node only. Two constants that were pinned by the old dual-tail cell are therefore **free**, and both
must be re-derived here:

**`V_bias_e`** — was forced to **0.65 V** because MN3_e shared `ntail`: at 0.9 V the MN3_e saturation
requirement (`V(ntail) > 0.42 V`) and the diff-pair requirement (`V(ntail) < 0.42 V`) were
*simultaneously impossible*, and both tails collapsed into triode at ntail ≈ 22 mV (SPICE,
2026-06-27). **That conflict is gone with the transistor.**
⇒ **Now set purely by the COMPARATOR's input common-mode range.** Do not inherit 0.65 V by default.

**`E_MAX_V`** — was **±55 mV** because Ce drove a tail and had to stay in the MAC's linear window.
⇒ **Now bounded ONLY by inject compliance and comparator range.** We need **~±100 mV** (§3), which
**would not have fitted** under the old ±55 mV constraint. **The jug's noise spec is only meetable
because the E-tail is gone.**

## 7. What "correct" looks like

The bit-accurate model reaches **81.96%** against a float ceiling of **82.13%** (EMNIST letters,
BIG topology, 24/8/16 chips). Seeds: 81.38 / 81.63 / 81.96 / 82.17.

**The SPICE circuit must reproduce the jug's code transitions**, not its analogue waveforms:
a crossing produces **exactly one ±1 code step**, and Ce retains **exactly** (V_Ce − sign·θ).
